Every release now includes the TV package (`ambilight-tv-vX.Y.Z.wgt`, launcher and service in one file), so the TV apps can be installed with [Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung) without building them. It is signed with a throwaway certificate and has to be re-signed for your TV, which Apps2Samsung does.
