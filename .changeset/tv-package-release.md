Every release now includes the TV package (`ambilight-tv-vX.Y.Z.wgt`, launcher and service in one file), so the TV apps can be installed with [Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung) without building them. It is signed with the Tizen SDK's default certificate and has to be re-signed for your TV, which Apps2Samsung does. The TV apps now carry the project version, shown in the launcher next to its title — please include it in bug reports.
